# Dashboard Design

El dashboard propuesto debe permitir visualizar los principales KPIs de segmentación de clientes y marketing bancario.

## Métricas Clave

- **Customer Lifetime Value (CLV):**  
\[
   CLV = Balance \times N°Productos \times Factor
\]

- **Retention Rate:**  
\[
   Retention = \frac{Clientes\ Retenidos}{Clientes\ Totales}
\]

- **Cross-Selling Index:**  
\[
   CSI = \frac{\text{Total de Productos Contratados}}{\text{N° de Clientes del Cluster}}
\]

## Secciones del Dashboard

1. **Visión General**
   - Número total de clientes
   - Distribución por cluster
   - Tasa de retención global

2. **KPIs por Cluster**
   - CLV promedio por segmento
   - Retention Rate por cluster
   - Cross-Selling Index por cluster

3. **Visualizaciones Recomendadas**
   - Barras comparativas (CLV, Retención)
   - Heatmap de correlaciones
   - Distribución de edad y productos
